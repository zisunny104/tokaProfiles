# tokaProfiles 多語系（I18N）

使用共用套件 `dev.toka:tokaI18n:0.1.0`（內嵌並 relocate 到 `dev.toka.profiles.internal.i18n`）。目前只有繁體中文 `zh-TW`，語言由 `config.yml` 的 `language` 決定。命令列工具與測試沒有伺服器環境時，透過 `Texts.get()` 使用 jar 內的 zh-TW。

## 已抽出的 key

共 **40** 個 key（`src/main/resources/lang/zh-TW.yml`）。

| 區 | 數量 | 內容 |
|---|---|---|
| `cmd.profiles.*` | 3 | 指令簡述、總用法、`title` 用法 |
| `help.profiles` | 1（15 行） | `/profiles help` 全部說明（含 title 與遷移工具），每行 `標籤|內容` |
| `msg.title.*` | 3 | 查看／清除／設定稱號的回應 |
| `err.*` | 19 | 權限、尚未就緒、用法、稱號驗證與查找錯誤；`err.path/activate/stage/import.*` 為啟動與遷移流程的例外訊息（會寫進後台 log，不含前綴） |
| `ui.*` | 5 | 城市通表單（標題、內容、無資料、關閉）、命令列匯出的密碼提示 |
| `log.*` | 8 | 後台文字、stage 目錄 `NOTICE.txt` 內容 |
| `status.noTitle` | 1 | 沒有稱號時的顯示字 |

程式中不再有中文字串字面值（註解與測試除外）。

## 每個指令的 help 位置

`/profiles help` → `help.profiles`。標籤 `*` 所有人，`title` 需要 `tokaProfiles.title.admin`。涵蓋：`/profiles`、`/profiles help`、`/profiles title <玩家> [稱號 | clear]`（別名 `titles`），以及遷移相關命令列工具的全部子命令與參數：`StagedProfileMigration stage|verify`、`ProfileMigration import|export-jdbc|plan-permissions`、`PlanResolution`。

## 顏色套用對照

| 位置 | 套用 |
|---|---|
| 玩家訊息前綴 | `§7[玩家資料]§r `（全插件固定） |
| 一般文字／變動值 | `§b`／`§a${n}§b` |
| 錯誤、拒絕、用法錯誤 | `§c`（用法本身 `§e`） |
| 成功（清除／設定稱號） | `§a` |
| help | 標題 `§6§l`，指令 `§e`，分隔 `§7-`，說明 `§b`，補充 `§7` |
| 後台 log | 不加方括號；文字 `§b`、數字 `§a`、警告 `§e`、成功 `§a`、失敗 `§c` |
| 城市通表單、`NOTICE.txt`、例外訊息 | 不使用色碼（表單與檔案不顯示 §） |

## 設定檔寫入

原本的 `getConfig().save()`（會洗掉註解）已改為 `ConfigEdit`：只用單行編輯改寫 `storage.active-directory`、`staged.*`、`migration.stage/confirm`，註解與其他內容保留（有 `ConfigEditTest`）。

## 待確認

1. 命令列工具的結果標記（`PROFILE_IMPORT_PASS`、`STAGE_RESULT`、`STAGE_VERIFY_PASS`、`PERMISSION_PLAN_PASS`、`PROFILE_EXPORT_PASS`、`PLAN_RESOLUTION_PASS`）與 CLI 的英文用法例外訊息，視為給腳本判讀的穩定 code／開發者訊息，**沒有**翻譯也沒抽出；若要中文化需另訂格式。
2. `ProfileMigration.permissionPlan` 產出的 LuckPerms 指令提案檔（英文標頭註解與 `lp …` 指令）以及 `IMPORT_FAILED.txt` 的英文內容是寫進檔案的資料，維持原樣。
3. 其餘 Model／Storage／Repository 的英文例外訊息（如 `Invalid name`）是給開發者看的，保留英文。
4. 玩家訊息前綴 `§7[玩家資料]§r ` 是新增的（原本沒有前綴）；稱號回應原本是純文字，請確認字樣。
5. `msg.title.set` 的稱號本身可能含 `§` 色碼，結尾以 `§r` 開頭顯示，不套用 `§a`。
6. `/profiles` 無參數仍開城市通（限玩家），沒有因為新增 `help` 而改變；`help` 保留為第一個參數的保留字。
7. 以單行編輯改寫設定時，若舊設定檔缺少要改的 key，會在該區塊末尾補上一行（舊流程的 `save()` 會整檔重寫）。
8. `StagedMigrationTest.interruptedBatchCanResumeWithoutDuplicateRecords` 以 2 秒輪詢等待第一個 checkpoint，冷啟動時偶爾逾時（本次建置第一次失敗、重跑通過）；與多語系無直接關係，未修改。
